# ☕ Coffee Machine Simulator (Python)

A command-line coffee machine simulator built with Python. This interactive program allows users to select drinks, insert virtual coins, and manage resources like water, milk, and coffee.

## Features

- Choose from Espresso, Latte, or Cappuccino
- Check machine resources using the `REPORT` command
- Insert coins (pennies, nickels, dimes, quarters) for payment
- Validates resources before making a drink
- Gives back change if extra money is inserted
- Turns off with the `OFF` command
